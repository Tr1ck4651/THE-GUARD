# THE-GUARD
## Система контроля доступа (СКУД)
Простая GUI-система контроля доступа, реализованная на Python с использованием библиотеки PyQt5 .
Позволяет управлять пропусками посетителей и сотрудников: создавать заявки, отслеживать вход/выход, просматривать историю и сохранять данные локально в формате JSON.
## Основные функции
- ✅ Авторизация пользователей (администратор, охранник, сотрудник)
- 📝 Создание индивидуальных и групповых заявок
- 📁 Прикрепление документов (фото паспорта, Excel-файлы)
- 🗂 Хранение заявок в JSON-файле
- 📊 Отображение графика активности за последние 24 часа
- 🔍 Валидация данных (телефон, email, возраст, паспорт и др.)
